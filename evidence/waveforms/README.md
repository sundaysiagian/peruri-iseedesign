# Bukti simulasi IGOR dengan GTKWave

Screenshot asli GTKWave, VCD, save file .gtkw, log regresi, testbench UART divider rilis dan manifest hash disertakan.
Gunakan BUKA_*.bat untuk membuka sinyal dan rentang waktu yang sama.
Neural first_inference adalah prefix persis VCD penuh untuk tampilan inferensi pertama; VCD penuh tetap tersedia di vcd/igor_neural.vcd.
Parameter testbench DWA: deadline 10000 clock dan freshness 250000 clock. Parameter rilis: 1000000 clock.
Testbench UART lama divider 8; bukti screenshot 04 memakai uji tambahan divider rilis 434.
Hasil seluruh suite 0 errors. Uji board fisik belum dinyatakan selesai.
