# Project Quartus IGOR siap dibuka

Pilih satu folder sesuai board fisik:
- MAX10_10M50DAF484C7G: DE10-Lite untuk pengujian lab; project quartus/igor_max10.qpf.
- IGOR_DE10_NANO: DE10-Nano untuk onsite; project quartus/igor.qpf.

Klik BUKA_PROJECT_QUARTUS.bat di dalam folder board pilihan, atau buka QPF melalui File > Open Project di Quartus.
Extract seluruh ZIP sebelum membuka project. Jangan mencampur SOF maupun pin assignment kedua board.
RTL, ROM assets, QPF/QSF/SDC, pin assignment, SOF, dan laporan timing sudah disertakan.
Setiap board memiliki README_MULAI_DI_SINI.md berisi langkah compile dan programming.
