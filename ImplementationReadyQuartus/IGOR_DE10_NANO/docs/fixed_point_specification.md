# Fixed point frozen before RTL
Position x/y: signed 24-bit with 8 fractional cell bits; cell=0.05 m. Valid map position 0 <= position <32768 (128 cells). Initial x=y=16384. Heading unsigned 8-bit phase: 256 codes/turn; modular addition is intentional.
v: unsigned 4-bit code; displacement per pose = v*16 position LSB (v/16 cell). dt=1/16 s, so v physical =0.05*v m/s. omega: signed 6-bit, -16..15 bins/pose, physical omega=pi*omega/8 rad/s. Grid limits may reject candidates. Horizon 20, no early termination (deterministic latency).
Sin/cos LUT: signed 16-bit Q2.14, nearest integer samples at 256 phases. Multiply displacement (signed16) by trig (signed16) -> signed32; arithmetic shift right14 rounds toward negative infinity. Sign extension precedes signed25 position addition. Overflow invalidates and latches arithmetic fault; out-of-map makes candidate illegal. Neither saturating positions nor silent wrap is allowed. Heading wrap is defined modulo 256.
Critics: sum of cost bytes along all poses (unsigned32); final Manhattan goal distance in Q8 cells; velocity penalty (15-v)*256. Weighted score =16*cost_sum + goal_distance + velocity_penalty, unsigned32 with explicit 33-bit overflow. Scores do not saturate: overflow invalidates and stops the command path. Collision if cost>=254, including unknown255. Candidate tie-break lowest index. Index=v_index*32+omega_index, omega=omega_index-16.
Multiplication cannot overflow signed32 for the legal operands (240*16384 <=3,932,160). Score legal upper bound is below 2^32; fault injection must test defensive detectors separately. Arithmetic saturation tests are NOT_APPLICABLE: design uses invalidation, not saturation.
Quantization bound: sampled sin/cos error <=0.5/16384; each displacement quantization <1 position LSB per axis per step. Relative to the same quantized heading recurrence, 20 steps <20.147 position LSB/axis (<3.94 mm). This is not a bound versus a continuous robot, sensor errors or footprint geometry. Underflow rounds by arithmetic shift. No floating point in synthesizable RTL.
